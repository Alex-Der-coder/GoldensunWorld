Nom : Moloch (Molok)
Djinn : + (Type Eau)
Effet : peut baisser l'Agilité
Plan :
Localisation : Pour la quatrième combo Stèle vous devez aller aux catacombes de Madra.
Pour l’avoir il vous faut Frimas (que vous obtenez dès que Piers rejoint votre groupe), descendez dans les sous-sols de la ville, continuez votre chemin en utilisant la psynergie Frimas sur les flaques. Vous arriverez enfin dans une bibliothèque où il y a une étagère sur laquelle est posé un coffre. Utilisez Secousse pour le faire tomber dans la salle du trône !
Allez-y et prenez la clé rouge dans le coffre puis rendez-vous dans le niveau inférieur dans lequel une porte vous bloque. Allez-y et utilisez la clé dans votre inventaire, maintenant vous avez encore une autre combo Stèle !!!!!!!!!!
